# Responsive UI audit — November 11, 2026

Reviewed sign-in, customers, customer dashboard/edit, history/archive, reports, locations, capture, upload/results/editor, account, help/feedback/inbox, shared walkthroughs.

Changes: bounded large-screen content, wrapping controls and text, larger touch targets, explicit button roles, permanent account password labels, readable placeholders, report controls scrolling with inventory, compact results navigation, corrected save wording, one source preview per editor, keyboard-aware invitation form, responsive sharing dialog, shared refresh recovery, and native navigation fallback plus location photo zoom/swiping. OCR/extraction and saved source evidence are unchanged.

Validation: real web screen components rendered with synthetic state at 320, 390, 768, 1024 and 1440 CSS pixels (75 layouts); browser DOM overflow checks, visual phone/tablet/desktop and editor checks; TypeScript checks and existing capture/recovery/barcode/sourcing/team test suites. Test fixtures are excluded from deployment.

Limits: fixtures are not live customer sessions. No physical iPhone/iPad or native simulator was available; native keyboard, dynamic type, pinch gestures and VoiceOver need device verification in TestFlight. Live signed-in multi-user capture was not performed during this UI audit.
